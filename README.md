# 哲学アキネーター

梟のミネルヴァが問いを重ねて、古今東西 226 の思想からあなたの思想を言い当てるブラウザゲームです。

**▶ 遊ぶ：https://xenoah.github.io/owl-of-minerva/**

サーバー不要の静的サイトで、GitHub Pages から配信しています。

## 遊び方

- **診断モード**：世界・知・生き方・社会についての問いに答えると、あなたの考えに最も近い思想と一致度を示します。
- **推理モード**：哲学者や学派を一つ思い浮かべると、時代・地域・主張を尋ねて当てにいきます。
- **思想図鑑**：収録されている全思想を、地域・時代・キーワードで絞り込んで読めます。

キーボードでは `1`〜`5` で回答、`Backspace` でひとつ戻れます。

## 自分の GitHub Pages で公開する

フォークして自分の Pages で動かす場合の手順です。

1. このフォルダの中身をリポジトリの `main` ブランチ直下に push する
2. GitHub のリポジトリで **Settings → Pages** を開く
3. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして Save
4. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

無料プランで Pages を使うには、リポジトリを Public にする必要があります。
ページ内のリンクはすべて相対パスなので、リポジトリ名を何にしても動きます。SNS でシェアしたときのリンク先（OGP）だけは `build.py` の `SITE_URL` を自分の URL に書き換えてからビルドしてください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 公開される本体。`build.py` が生成するので直接は編集しない |
| `apple-touch-icon.png` | iPhone でホーム画面に追加したときのアイコン |
| `src/traits.js` | 質問になる命題の一覧（86 問）と地域・分野の定義 |
| `src/data1.js`〜`data4.js` | 思想データ（古代〜中世／近世〜19世紀／20世紀以降／アジア・アフリカ・中南米） |
| `src/engine.js` | 推論エンジン（ベイズ更新と、情報利得による次の質問の選択） |
| `src/template.html` | 画面の HTML・CSS・UI |
| `build.py` | `src/` をまとめて `index.html` を作る |
| `sim.js` | 全思想になりきって遊ぶ検証シミュレーション |

## 思想を追加・修正する

思想は `src/data*.js` に次の形で書かれています。

```js
P("stoic", "ストア派", "Stoicism", -300, "gr",
  "ゼノン、セネカ、エピクテトス、マルクス・アウレリウス",   // 代表的な思想家
  "自然に従って生きよ／アパテイア（情念からの自由）",       // キーワード
  "自分の力で変えられるものと……",                          // 説明
  "virt2 calm2 nat2 cosmo2 telos2 det1 pant2 ...",          // 各命題への立場
  "lm");                                                    // 分野
```

- **立場**：`src/traits.js` の命題キーに数値を付けて並べます。`2` 強く肯定、`1` 肯定、`0` 保留（あえて判断しない）、`-1` 否定、`-2` 強く否定。書かなかった命題は「特に立場を示さない」扱いになります。
- **年**：生まれたおおよその年。紀元前はマイナス。
- **地域**：`gr` 古代ギリシア・ローマ、`eu` `de` `fr` `uk` `us` `au` `it` `ru`、`cn` `jp` `kr`、`in` `tb`、`me` イスラーム圏・中東、`af` `la`、`ww` 世界各地。
- **分野**：先頭の文字が主な分野。`m` 存在論、`e` 認識論、`l` 倫理・生き方、`s` 社会・政治、`p` 心の哲学、`k` 科学・論理・言語、`r` 宗教、`a` 美学。

編集したら、ビルドして検証します（Python 3 と Node.js が必要）。

```sh
python3 build.py      # index.html を作り直す
node sim.js           # 全思想が当てられるか確認（数分かかります）
node sim.js pairs     # 立場がよく似ていて紛らわしい組を一覧
```

`build.py` は Node.js があれば、未知の命題キーや地域コード、重複した ID を見つけてエラーで止まります。

## しくみ

各思想について「この命題を聞かれたら、どう答える確率が高いか」を持っておき、回答のたびに全思想の確率をベイズの定理で更新します。
次の質問は、答えを聞いたときに候補の絞り込みが最も進む（情報エントロピーが最も下がる）ものを選ぶので、同じ遊び方でも質問の順番は毎回変わります。
